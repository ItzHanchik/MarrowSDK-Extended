# AuroraRP 1.0.0 — что где лежит и что делать

Этот файл — пошаговая инструкция. Читай сверху вниз, ничего не пропуская.
Ниже — короткая версия, в конце — таблица «что где лежит в архиве».

---

## 0. Из чего состоит мод (три части)

| Часть | Файл | Куда ставится | Кому нужен |
|---|---|---|---|
| **Логика** | `AuroraRP.dll` | `<BONELAB>\Mods` | хосту и тем, кто хочет меню, роли, магазин |
| **Красота + настройки** | палет (`pallet.json`, бандлы, `config.json`) | `%USERPROFILE%\AppData\LocalLow\Stress Level Zero\BONELAB\MODS\AuroraRP` **или** mod.io (тогда качается сам) | всем; у обычных игроков скачивается автоматически |
| **Автообновление** | `AuroraRPUpdater.dll` | `<BONELAB>\Plugins` | один раз; дальше сам держит мод, палет и зависимости |

Что уже готово и лежит на GitHub (собрано автоматически, делать не надо):

🔗 **https://github.com/ItzHanchik/MarrowSDK-Extended/releases/tag/aurorarp-v1.0.0**

- `AuroraRPUpdater.dll` — плагин автообновления (собран CI против MelonLoader 0.6.6);
- `AuroraRP-Thunderstore-1.0.0.zip` — пакет для Thunderstore;
- `AuroraRP-pallet-src-1.0.0.zip` — конфиг и документы палета.

Осталось доделать два места: **`AuroraRP.dll`** и **палет с моделями** — они собираются только в Unity
(игровые сборки есть только на твоей машине).

## 1. Собрать мод и палет в Unity (≈10 минут, один раз)

### 1.1 Что должно быть установлено
1. **Unity 2021.3.16f1** (через Unity Hub) — именно эта версия, как у MarrowSDK.
2. **MarrowSDK** в проекте: Window → Package Manager → + → Add package from git URL →
   `https://github.com/StressLevelZero/MarrowSDK.git`
3. **BONELAB + MelonLoader 0.6.6** на этом же компьютере (MelonLoader нужен, чтобы появились
   папки с игровыми сборками — без них Unity не соберёт мод).
4. **.NET SDK 6 или новее** — для сборки DLL (https://dotnet.microsoft.com/download).

### 1.2 Положить файлы в проект
Скопируй папку `AuroraRP` из архива в свой Unity-проект так, чтобы получилось:

```
<Проект>/Assets/AuroraRP/Mod~        ← исходники мода (Runtime/*.cs, AuroraRP.csproj)
<Проект>/Assets/AuroraRP/Editor      ← меню AuroraRP в Unity
<Проект>/Assets/AuroraRP/Updater     ← исходники плагина автообновления
<Проект>/Assets/AuroraRP/Pallet      ← конфиг палета (config.json)
<Проект>/Assets/AuroraRP/Thunderstore← пакет для Thunderstore
<Проект>/Assets/AuroraRP/Docs        ← документация
<Проект>/Assets/AuroraRP/update.json ← манифест автообновления
```

> Папки MarrowSDK (`Scripts`, `Data`, `Plugins`) в архив не входят — они уже есть в твоём
> Unity-проекте, ты их ставил пунктом 1.1.

### 1.3 Кнопки в Unity (меню **AuroraRP** сверху)
| Кнопка | Что делает |
|---|---|
| **0. Проверить окружение** | показывает найденные пути; кнопка «Указать папку BONELAB...», если игра не нашлась сама |
| **1. Настроить сборку мода** | создаёт `Mod~/AuroraRP.csproj` и скрипты сборки под твои пути |
| **2. Создать контент палета** | делает терминал, принтер денег и «набор красоты» (иконки, скин меню, партиклы, купюра, звуки) |
| **3. СОБРАТЬ ВСЁ** | главная кнопка: DLL + апдейтер + контент + палет + архивы + установка в игру |
| **4. Открыть папку сборки** | открывает `<Проект>/Builds` |
| **5. Установить последнюю сборку в BONELAB** | копирует DLL в `Mods`, апдейтер в `Plugins`, палет в `MODS` |
| **6. Собрать палет-архив** | пересобрать только `AuroraRP-pallet-<версия>.zip` |

Порядок: **0 → 1 → 2 → 3**.

### 1.4 Что получится
В `<Проект>/Builds`:
- `AuroraRP_v1.0.0.zip` — архив для игроков (DLL + апдейтер + палет + инструкция);
- `AuroraRP-pallet-1.0.0.zip` — палет для mod.io и автообновления;
- в `Assets/AuroraRP/Mod~/bin/AuroraRP.dll` — код мода;
- в `Assets/AuroraRP/Updater/bin/AuroraRPUpdater.dll` — плагин.

**Проверка в игре:** зайти в любой уровень, двойной щелчок **обоих** триггеров — открывается меню
над левой рукой. Если не открывается — смотри `BONELAB\MelonLoader\Latest.log`.

## 2. Что и куда выкладывать

| Куда | Что заливать | Зачем |
|---|---|---|
| **GitHub → Releases → `aurorarp-v1.0.0`** | `AuroraRP.dll` и `AuroraRP-pallet-1.0.0.zip` (кнопка *Edit* → *Attach binaries*) | отсюда игроки с плагином скачивают обновления; ссылки в `update.json` уже на этот релиз |
| **mod.io** (страница BONELAB) | `AuroraRP-pallet-1.0.0.zip` | чтобы обычные игроки получали палет автоматически: Fusion скачает его сам |
| **Thunderstore** | `Builds/AuroraRP-Thunderstore-1.0.0.zip` (собирается скриптом `AuroraRP/Thunderstore/pack_thunderstore.cmd`) | установка мода в один клик (Gale / r2modman) |

Порядок именно такой: сначала релиз (иначе автообновление будет ругаться на отсутствующий файл),
потом mod.io, потом Thunderstore.

### mod.io подробнее
1. Заходишь на mod.io → BONELAB → **Add mod** → имя `AuroraRP`, загружаешь `AuroraRP-pallet-1.0.0.zip`.
2. Смотришь **Mod ID** (число в кабинете разработчика).
3. Вписываешь его в `Assets/AuroraRP/Pallet/config.json` в поле `"modioModId"`.
4. Unity → **3. СОБРАТЬ ВСЁ** → заново загружаешь палет на mod.io и прикладываешь к релизу.

Теперь у любого игрока без палета Fusion сам предложит и скачает контент прямо в игре.

## 3. Настройка системы (всё в палете)

**Главный файл:** `Assets/AuroraRP/Pallet/config.json` — уезжает к игрокам вместе с палетом.

| Что настраивается | Ключи |
|---|---|
| Стартовые деньги, переводы | `startBalance`, `transferHoldSeconds`, `transferHandDistance`, `transferStepSmall/Big`, `transferMax` |
| Двери | `doorPrice`, `doorMaxPerPlayer`, `doorPoliceForbidden`, `doorSellPresses`, `doorRefundPercent` |
| Магазин и роли | `dealerMarkupPercent`, `requireWeaponLicense`, `allowSelfRoleSelect`, `hitmanMaxCount`, `shopItems[]` |
| Грабежи и аресты | `robHoldSeconds`, `robPercent`, `robCooldown`, `arrestsEnabled`, `arrestFine` |
| Принтеры денег | `printerBarcode`, `printerInterval`, `printerPayout` |
| Игроки без мода | `peerBridgeEnabled`, `passiveTransferAmount`, `passiveDoorBuyEnabled` |
| Красота из палета | `usePalletVisuals`, `transferFxEnabled`, `transferFxSeconds` |
| Раздача палета | `modioModId`, `contentBarcode`, `autoPullPallet` |
| Discord-банк | `discordWebhookPlain` (вставить ссылку вебхука — при первом запуске она зашифруется) |

Хочешь поменять что-то **только у себя**: положи такой же `config.json` в
`MelonLoader/UserData/AuroraRP/config.json` — он перекрывает палетный и не теряется при обновлениях.

## 4. Что делает обычный игрок

**Ничего не ставит.** Единственное, что у него появляется, — палет, и тот скачивается сам.

Что он может без мода: видеть и трогать предметы (терминал, принтер, двери), **платить** (подержать
руку игрока с модом), **покупать двери** (подержаться за дверь, стоя на месте). Всё это считает хост.

Чего не будет: меню, выбора роли, магазина, браслета с балансом — интерфейс рисует только код,
а палет скрипты не исполняет (ограничение BONELAB, не наше).

Кто хочет полный набор — ставит `AuroraRP.dll` (+ BoneLib, LabFusion) или один плагин
`AuroraRPUpdater.dll`, который сам всё скачает и будет обновлять.

## 5. Как выпускать обновления

1. Подними версию в четырёх местах:
   `AuroraRP/Mod~/AuroraRP.csproj`, `AuroraRP/Editor/AuroraRpPaths.cs` (`ModVersion`),
   `AuroraRP/Thunderstore/manifest.json`, `AuroraRP/update.json`.
2. Unity → **3. СОБРАТЬ ВСЁ**.
3. Закоммить и поставь тег: `git tag -a aurorarp-v1.1.0 -m "AuroraRP 1.1.0" && git push origin aurorarp-v1.1.0`.
4. GitHub Actions (файл `.github/workflows/build.yml`) сам соберёт плагин и приложит к релизу
   `AuroraRPUpdater.dll`, Thunderstore-пакет и палет-исходники.
5. Приложи к релизу `AuroraRP.dll` и `AuroraRP-pallet-<версия>.zip` (или настрой секрет
   `BONELAB_ASSEMBLIES_URL` — тогда CI соберёт и мод, см. `AuroraRP/Docs/PUBLISHING.md`).
6. Обнови палет на mod.io и в `update.json` (`version`, `dll`, `pallet`, `palletVersion`).

## 6. Если что-то не работает

| Симптом | Что делать |
|---|---|
| Меню не открывается | проверь, что `AuroraRP.dll` лежит в `<BONELAB>\Mods`, BoneLib установлен; смотри `MelonLoader\Latest.log` |
| Unity: «Не найдена папка Il2CppAssemblies» | MelonLoader не установлен или неверный путь → **AuroraRP → 0. Проверить окружение → Указать папку BONELAB** |
| Палет не качается у игроков | не заполнен `modioModId`; у игрока должен быть LabFusion |
| Игрок без мода не платит | игрок должен именно **держать руку** другого игрока ~5 секунд, стоя рядом |
| Дверь покупается сама | подними `passiveDoorHoldSeconds` (или выключи `passiveDoorBuyEnabled`) |
| Автообновление пишет ошибку про `AuroraRP.dll` | файл ещё не приложен к релизу — приложи (шаг 2) |
| Сборка палета падает | у палета должно быть имя `AuroraRP`; подробности — `AuroraRP/Docs/PUBLISHING.md` |

## 7. Что где лежит в архиве

```
ПРОЧТИ_МЕНЯ.md                     ← этот файл
README.md                          ← общее описание репозитория
release-notes.md                   ← текст описания релиза
.github/workflows/build.yml        ← автосборка плагина в GitHub Actions

AuroraRP/
├── README.md                      ← полная документация мода (роли, экономика, функции)
├── update.json                    ← манифест автообновления (версия, ссылки на DLL и палет)
├── Mod~/                          ← ИСХОДНИКИ МОДА (логіка)
│   ├── Runtime/                   ← код: роли, деньги, двери, магазин, меню, сеть
│   ├── AuroraRP.csproj            ← проект сборки DLL
│   └── build_mod.cmd / .sh        ← сборка DLL без Unity (если есть dotnet)
├── Editor/                        ← меню AuroraRP в Unity (0..6)
├── Updater/                       ← плагин AuroraRPUpdater (автообновление)
├── Pallet/config.json             ← ГЛАВНЫЙ КОНФИГ системы (роли, цены, лимиты)
├── Thunderstore/                  ← пакет для Thunderstore + скрипт упаковки
└── Docs/PUBLISHING.md             ← как публиковать (mod.io, GitHub, CI, сборки)
```
