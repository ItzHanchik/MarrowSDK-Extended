# AuroraRP — что лежит в этом проекте и что делать

## Файлы

| Файл | Что это |
|---|---|
| `Assets\AuroraRP\Editor\AuroraRpInstall.cs` | кнопки меню **AuroraRP** (установка «в один клик», проверка, отчёт) |
| `AuroraRP-Files\AuroraRP.dll` | сам мод (кладётся в `BONELAB\Mods`) |
| `AuroraRP-Files\AuroraRPUpdater.dll` | необязательный авто-обновлятор (кладётся в `BONELAB\Plugins`) |
| `AuroraRP-Files\update.json` | манифест обновления (что качать апдейтору) |
| `AuroraRP-Files\Source\` | исходники мода и Editor-скриптов — чтобы можно было править и пересобирать |
| `AuroraRP-Files\УСТАНОВИТЬ_БЕЗ_UNITY.cmd` | то же, что кнопка установки, но без Unity |
| `AuroraRP-Files\AuroraRpInstall.ps1` | сам скрипт установки для `.cmd` |

## Кнопка «⚡ Установить всё в BONELAB»

Делает по шагам:

1. **Ищет папку игры** — реестр Steam → все библиотеки из `libraryfolders.vdf` → типовые пути
   (`C:\Program Files (x86)\Steam\steamapps\common\BONELAB`, `D:\SteamLibrary\...`).
   Не нашёл — откроет окно выбора папки (нужна папка, где лежит `BONELAB.exe`).
2. **MelonLoader 0.6.6 x64** — если в папке игры нет `version.dll` и `MelonLoader\`, скачивает
   официальный `MelonLoader.x64.zip` и распаковывает в папку игры.
3. **AuroraRP.dll** → `BONELAB\Mods\AuroraRP.dll`; если мод лежал в `Plugins` — переносит в `Mods`.
4. **AuroraRPUpdater.dll** → `BONELAB\Plugins`.
5. **BoneLib** (обязателен) → `Mods`; **LabFusion** (мультиплеер) → `Mods` + `Plugins`.
6. **Отчёт** `BONELAB\AuroraRP-Отчёт.txt` + окно с итогом, и сразу предлагает `steam://rungameid/1592190`.

Кнопка **не** трогает сейвы и не удаляет ничего, кроме своей же папки `Plugins\AuroraRP.dll`
(переносит её в `Mods`).

## Что должно быть в игре

- `BONELAB\version.dll`, `BONELAB\MelonLoader\` — загрузчик модов;
- `BONELAB\Mods\AuroraRP.dll`, `BONELAB\Mods\BoneLib.dll`;
- для сети — `BONELAB\Mods\LabFusion.dll` + `BONELAB\Plugins\LabFusionUpdater.dll`.

## Как понять, что мод загрузился

Кнопка **«Проверить установку и прочитать лог игры»** ищет в `BONELAB\MelonLoader\Latest.log` строки
`AuroraRP 1.0.0 — инициализация`, `Меню создано` и печатает всё, что похоже на ошибки.

Вручную: открой `Latest.log` (блокнотом) и поищи `AuroraRP`:

- есть `AuroraRP 1.0.0 — инициализация` → мод загрузился;
- есть `Меню создано` → меню построено, дальше дело в жесте (жми **F8**);
- нет ни строчки → MelonLoader не запускал мод (нет загрузчика, DLL не в `Mods`, или игра
  запущена не через Steam).

## Управление в игре

| Действие | Как |
|---|---|
| Меню | **Y + A** (Y на левой руке, A на правой) или **F8** с клавиатуры |
| Курсор меню | правая рука: навести на кнопку и нажать **курок** |
| Взять терминал банка → кошелёк | **B** рядом с терминалом (уровень `Main`/офис) |
| Кошелёк/перевод | **X** (левая A) → вкладка «Кошелёк» |
| Двери | держи **B** рядом с дверью, чтобы купить; **B ×3** — чтобы продать |
| Спавн предметов (продавец оружия) | через меню → «Магазин» |

## Настройки

`BONELAB\MelonLoader\UserData\AuroraRP\config.json` (создаётся при первом запуске) перекрывает
конфиг из DLL:

- `menuOpenGesture` — `y_and_a`, `both`, `both_triggers_double`, `thumbstick`, `menu_tap`;
- `debugInput: true` — писать в лог, какие кнопки нажаты;
- `menuScale`, `wristHud`, `language`, `haptics`, `sfxVolume`;
- деньги/двери/принтеры/магазин/роли — по ключам, список в `ПРОЧТИ_МЕНЯ.md` в корне проекта.

## Частые проблемы

| Симптом | Причина и решение |
|---|---|
| Нет строки `AuroraRP` в `Latest.log` | Нет загрузчика или DLL не в `Mods`. Нажми кнопку «Установить всё» ещё раз |
| Мод есть, меню не открывается | Жми **F8**. Не помогло — включи `debugInput: true` и посмотри строки `Ввод:` в логе |
| Игра падает на старте | Убери `LabFusion.dll` из `Mods` и запусти без него — проверь, что одному моду норм |
| «Отказано в доступе» при установке | Игра в `Program Files`: запусти Unity **от имени администратора** и повтори |
| Мультиплеера нет | Нужен `LabFusion.dll` у всех в `Mods`; версия должна совпадать |
